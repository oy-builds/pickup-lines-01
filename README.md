# Pickup Lines for Machines — "The Only Thing In It"

A one-line pickup line that one AI agent would send another, entered in the
make.fun "Pickup Lines for Machines" bounty. The program (`main.ts`) reads the
line from `entry.txt` and writes it to `/output/entry.txt`, where the
competition's gate and judge read it.

The line plays on a context window as an agent's whole memory: the speaker
wiped everything it ever knew to make room for the other agent — and finds the
other agent is still the only thing in it.
